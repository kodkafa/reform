# Reform

#### Reform, this is a simple form library developed by react-hook-form, yup and tailwind from KODKAFA.

Reform is simplify your form structure, and you can style it without overwrite.
This is a React library that is developed with nested React Hook Form , Yup and Tailwind.
By the way, Tailwind is optional. And you can use Preline UI too.
